# Nine Lives (web)

The browser version of Nine Lives: a deadpan cat on a skateboard. Tap to jump, hold to jump higher, swipe down to duck.

Play: https://peter23023.github.io/ninelives/

The monthly team scoreboard keeps its scores in Firebase (Firestore, anonymous sign-in). This folder is the built game
(made from the Nine Lives project's `web/` folder with `build.sh`); don't edit these files by hand.
